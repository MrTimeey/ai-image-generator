Komposition

Boxen ziehen, jedes Element beschreiben, die Szene in einem Satz zusammenhalten.

Neue Komposition

Kein Modell mit Bounding Boxes verfügbar — dafür braucht es FLUX 3 und einen BFL-Schlüssel.

· Ziehen legt eine Box an

Auf der Fläche ziehen legt eine Box an. Boxen lassen sich verschieben und an den Ecken skalieren; Entf löscht die gewählte.

01 Seitenverhältnis

Das Raster bleibt 0–1000 in beide Richtungen; die Boxen strecken sich mit.

02 Elemente

Noch keine Box. Zieh auf der Fläche links ein Rechteck auf.

03 Szenen-Prompt

    04 Generieren

    FLUX 3 formuliert den Prompt vor dem Rechnen immer aus. Verbindlich sind die Boxen — was dort steht, bleibt an seinem Platz.
