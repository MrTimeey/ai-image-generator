AI Image Generator

Claude-Skill

Ein Skill ist eine Anleitung, die Claude Code bei passenden Anfragen von selbst heranzieht. Ist er installiert, genügt „erzeug mir ein Titelbild für den Blogpost“ — Claude wählt Modell und Seitenverhältnis, ruft diese Instanz auf und legt das fertige Bild ab. Ohne den Skill müsste man ihm jedes Mal die API erklären.

Was er kann

  • • Modellwahl als Entscheidungshilfe — wann FLUX.2, wann gpt-image-2 (Text im Bild), wann Kontext (Bildbearbeitung), was jeweils kostet.
  • • Seitenverhältnisse für die üblichen Fälle: Titelbild 16:9, Poster 2:3, Social 1:1, Banner 21:9.
  • • Referenzbilder — wie viele welches Modell auswertet und wie ein Bearbeitungs-Prompt aussehen muss.
  • • Ein CLI ohne Abhängigkeiten (aig.py, nur Python-Standardbibliothek): erzeugen, auflisten, Metadaten, herunterladen, löschen, Guthaben.
  • • Grenzen: dass jedes Bild Geld kostet und rm endgültig ist — damit Claude nicht ungefragt vierzig Varianten erzeugt.

Installation

Als Plugin

empfohlen

Zwei Befehle in Claude Code. Updates holt man später mit /plugin marketplace update mrtimeey — ohne etwas herunterzuladen. 

/plugin marketplace add MrTimeey/ai-image-generator
/plugin install ai-image@mrtimeey

Von Hand

Ohne GitHub, und man sieht vorher, was drinsteht. Das Archiv enthält ai-image/SKILL.md und ai-image/scripts/aig.py — die Standardadresse darin zeigt bereits auf diese Instanz.

Skill herunterladen (ZIP)

Danach entpacken:

mkdir -p ~/.claude/skills
unzip -o ~/Downloads/ai-image-skill.zip -d ~/.claude/skills

Danach: Schlüssel hinterlegen

Der Skill braucht einen API-Key dieser Instanz. Einen erzeugst du unter API-Keys — dort stehen die fertigen Befehle mit dem Schlüssel schon eingesetzt. Der Ablageort:

Alternativ AIG_TOKEN als Umgebungsvariable setzen. AIG_URL überschreibt die Adresse.
